## 進め方
1. 色と形の定義を `src/index.css` の `.demo-app` に入れる（本物の画面には当てない）。
2. `/demo` の画面を1つずつ作り替える（打刻 → 発注 → 報告書 → 警告）。
3. 見てもらって良ければ、本物の画面に広げる。
- 配管（DB・Edge Function・計算ロジック）には触れない。印刷（報告書・警告レポートの紙面）は白黒のまま。

## 形
- カードの角丸 24px、中の小さな面 12〜16px、ボタン・タブ・切り替えは丸い錠剤（999px）。
- 影は1つだけ: `0 1px 0 rgba(255,255,255,.8) inset, 0 12px 32px -12px rgba(15,23,42,.18)`。
- 橙のカードだけ `linear-gradient(150deg,#fb923c,#f97316 55%,#ea580c)`。
- PC: 左に浮いたガラスのメニュー（選択中は紺の塗り）。スマホ: 下に浮いた丸いバー。
- 押す場所は44px以上、文字は12px以上。色だけで伝えない（文字も添える）。

## 文字
- 字体は端末の標準（`system-ui` 先頭。`.demo-app` に設定済み）。変えない。
- 数字は大きく太く（`tabular-nums`）、単位（分・件・円）は小さく添える。
- 見出しは「何の画面か」をそのまま書く。「〜を、〜に。」の対句、絵文字、英語の飾り、同じ説明の繰り返しは使わない。
- 説明文を足すより、形で分かるようにする（例: 帯の中に「待機 72分」と直接書く）。
