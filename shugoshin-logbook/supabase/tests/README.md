# DB テスト

`security_checks.sql` は、証拠テーブルへの書き込み経路と関数の実行権限の回帰テストです。
SQL Editor に貼って実行すると、結果が例外メッセージとして返り、**常にロールバックされます**。
`[OK]` 以外の行があれば、権限設計が崩れています。マイグレーションを適用したあとに毎回実行してください。

`server_side_report_totals.sql` は、日報の数値のサーバー計算（待機時間・待機料・提出 RPC・料率表・月次ビュー）のテストです。
同じ入力・期待値の表を、TypeScript 側（`src/lib/serverTotalsParity.test.ts`）も読んで検証します。同様にロールバックされます。

**結果の先頭に「⚠⚠⚠ 省略 N 件」が出たら、その分は検証されていません**（前提のデータが無いと項目が省略されます。合格ではありません）。
